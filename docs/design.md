# Fiber Lens UI 设计方案

> 版本：v0.5 设计稿（实现中） ｜ 状态：已与需求方确认方向
> 本文档是 dsh-fiber-lens 视觉与交互设计的唯一权威来源，实现以此为准。
> v0.5 修订（推翻 v0.4 双镜头架构）：机制视图与会话视图经实际使用验证**没有价值**——
> 264 节点全景图回答"系统里有什么"，会话参与集是遥测思路；用户真正的问题是
> "**这个正在跑的插件**在和谁协作"。收敛为单一主视图：焦点链（Focus Chain）。

---

## 1. 设计定位

**"注意力放大镜"** —— 不是全景地图，而是把视口内的一切渲染预算都花在
**当前正在运行的插件及其上下游链条**上，无关节件一律不渲染。

审美对标：Linear 的克制 + VS Code 调试面板的信息密度 + 暗色科技感。

真实数据特性：

- 264 个 fiber 实例聚合为百余个逻辑插件（groups）
- 秒级差量轮询（ping/version + snapshot）
- version 事件流由 Cordis `internal/status` / `internal/plugin` / `internal/service` 驱动

**时间纪律**：fiber-lens 不保留时间线。事件的精确顺序、时间戳、因果链归
Trajectory 视图；fiber-lens 只回答"现在"。

## 3. 焦点链（Focus Chain）

### 3.1 链的计算（纯客户端，两个 BFS）

```text
上游（它为什么能跑）：节点.inject ─→ 服务名 ─→ services.ownerUid ─→ provider 节点 ─→ 递归
下游（谁靠它跑）：    节点.provides ─→ 服务名 ─→ 谁的 inject 含它 ─→ consumer 节点 ─→ 递归
```

约束：visited 防环；跳数上限 ±3，之外折叠为 `+N` 端点节点（点击续展）；
孤立节点（无 inject 无 provides）显示"该插件独立运行"标注。

### 3.2 布局：依赖跳数分层（不是挂载树）

```text
 ← 上游 hop -2 │ ← 上游 hop -1 │ ★ 焦点（0 列）│ 下游 hop +1 → │ 下游 hop +2 →
```

- 列 = 依赖跳数，自左向右流动；焦点节点垂直居中于 0 列
- 边 = 服务依赖（主角，实线带流向箭头）；**挂载边在此模式下不渲染**
  （它讲部署结构，不讲运行链条）
- 同列节点按名字排序，垂直均匀分布；手写布局，零依赖

### 3.3 焦点来源与跟随策略

- **默认自动跟随**：最近发生状态流转的插件成为焦点（由快照 diff 得出，
  无需会话数据——这是砍掉会话镜头后"当前运行"的诚实信号）
- **点击接管**：用户点击任何节点即切为手动焦点，自动跟随暂停
- **空闲恢复**：Esc 或 3 秒无操作恢复自动跟随
- **防眩晕**：焦点切换最少停留 1.5s（滞回）；切换用 300ms 镜头飞行，不瞬移

### 3.4 注意力纪律

| 元素 | 处理 |
|------|------|
| 链上节点 | 全色渲染 |
| 链外节点 | **不渲染**（不是变暗——从画布消失） |
| 焦点节点 | 发光描边 + 呼吸（唯一常驻动画，见 §6 例外） |
| 链上状态流转中的节点 | 按视口动画规则正常 morph/脉冲 |

## 4. 视口与状态存活纪律

264 全景漂移问题在焦点链下大半自动消失（链上仅数十节点），剩余条款：

1. **面板开合不卸载**：用 CSS 隐藏（`display:none`），不 unmount——
   视口 transform / 选中节点 / 折叠状态全部跨开合存活
2. **相机补偿**：布局重算前记录视口中心的世界坐标，重算后反解 transform，
   让同一世界坐标留在原屏幕位置
3. **双击复位 = 适应内容**（fit-to-content：内容包围盒居中入镜），不是回原点
4. 视口/选中属"面板会话"级；折叠偏好可入 localStorage（跨重启）

## 5. 动画纪律

**核心原则：动画是视口内的瞬时叙事；视口外的事件不补放动画，进入持久记录（ticker）。**

1. **视口授予**：diff 出的新增/消失/状态变化键先与当前可见世界矩形求交，
   只有相交节点挂动画类；视口外节点直接以最终状态渲染
2. **一次性消费**：平移到某区域不回放该区域历史动画；历史由 ticker 回答
3. **合并窗口**：300ms 内的连续 diff 合并为一批动画，防止高频事件闪屏
4. **状态 diff 是一等公民**：按 (uid → state) 对比驱动 morph + 脉冲环，
   不只是键增删（v0.4 实现缺失此层，导致"流转动画不存在"）
5. **布局位移平滑过渡**：节点位置变化用 FLIP transform 过渡，不硬跳
6. **常驻动画唯一例外**：failed 节点红色呼吸脉冲，直到恢复或处置；
   焦点节点的发光描边呼吸
7. 全部 CSS transitions/keyframes，零 JS 动画库；`prefers-reduced-motion` 全量静态回退

## 6. 视觉系统

| 元素 | 方案 |
|------|------|
| 主题 | `--dsw-alias-*` token 全量对齐 DSH Web UI，亮/暗跟随 |
| 状态色板 | 六色：active `#34d399` / pending `#fbbf24` / loading `#22d3ee` / unloading `#fb923c` / failed `#fb7185` / disposed `#64748b` |
| 字体 | JetBrains Mono / ui-monospace；数字 `tabular-nums` |
| 状态指示 | CSS 发光圆点（box-shadow 光晕），不用 emoji |
| 面板 | 居中 portal 浮层（document.body，z-index 99999），可拖拽移动 |

## 7. 事件 ticker

右侧面板内嵌（180px）：滚动列出最近 20 条状态流转
（`agent-loop pending→loading 14:32:07`），新事件顶部滑入；
点击条目 → 焦点跳到该插件 + 镜头飞行。它是"视口外事件"的持久记录，
也是手动焦点的一个入口。

## 8. 代码分层管道（严格单向）

```
snapshot（轮询：fiber 状态 + 分组）
  → diff（纯函数：键增删 + uid→state 变化 + 300ms 合并窗口）
    → focus（焦点解析：自动跟随 / 手动接管 + 滞回）
      → chain（纯函数：双向 BFS，±3 跳，防环）
        → layout（纯函数：依赖跳数分层，自左向右）
          → render（SVG/React，只读布局结果）
            → animate（CSS 类，changeKind × 视口求交驱动）
```

- diff / chain / layout 均为独立纯函数模块；store 只持有快照并触发管道
- Host 保持零硬 inject；快照字段无需扩展
- 面板隐藏时代码继续活着但停止轮询（现状已如此）

## 9. Host API

- `GET /api/fiber-lens/ping` → `{ version }`（现有）
- `GET /api/fiber-lens/snapshot` → `{ version, at, fibers, services, groups }`（现有）

## 10. 交付轮次

| 轮次 | 内容 | 验收点 |
|------|------|--------|
| P1 | 焦点链骨架：双向 BFS + 依赖分层布局 + 服务边 + 缩放平移 + 列表跳转入口；删除机制/会话视图 | 点列表行 → 链条出现；无关节点零渲染 |
| P2 | 动画纪律实现：状态 diff morph + 视口授予 + 合并窗口 + ticker + 镜头飞行 + 自动跟随/滞回 | 起一个插件能看到链上 pending→active 流转且不闪屏 |
| P3 | 视口存活（开合不卸载/相机补偿/fit-content）+ 视觉打磨 + reduced-motion | 关开面板状态全在；双击复位永远看到内容 |
